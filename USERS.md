# Who is using C++ for BPF?

This is a directory of projects and organizations that write BPF programs in
C++, with or without the cpp-bpf library. It helps users find each other and
share experience, and it shows which use cases matter for upstream work in
clang, libbpf and the kernel. The users themselves maintain the list.

## Adding yourself

Open a pull request that adds an entry to the list below, in alphabetical
order:

    N: Name of the project or organization
    D: Description
    U: Usage: program types, features, kernel versions
    L: Link with further information (optional)
    Q: Contacts available for questions, e.g. GitHub handles (optional)

Example entry:

    * N: Example Project
      D: Example Project traces file I/O for a C++ storage engine
      U: fentry/fexit programs, ring buffer, CO-RE, Linux 6.6 and newer
      L: https://example.com/
      Q: @example-user
